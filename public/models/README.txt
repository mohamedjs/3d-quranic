Drop character models here (optional). When a file is present it replaces the built-in
procedural character automatically; when absent the game uses the procedural one.

  player.glb   the child you play        (target height 1.25 m)
  farmer.glb   Grandpa Salim             (paths are set per NPC in data/encounters.json → character.model)
  trader.glb   Uncle Hamdan
  grandma.glb  Grandma Amina

Animations are found by clip name (Mixamo-style exports work): idle, walk, run, talk.
Draco or Meshopt compressed GLBs are supported. Keep textures ≤ 2K.
